Algorithmic Trading Asked by @AlexK • 2 days ago

Why execute your trading bots in native MQL5 on MT5 rather than pure Python or REST API bridges?

A
David Anthony Jones (Alu) ✓ Founder Answer

Latency, reliability, and broker tick fidelity. REST API bridges introduce 100–300ms network roundtrips and TCP handshake overhead on every tick. MQL5 compiles down to native 64-bit machine code executing inside the terminal process itself with sub-0.5ms tick latency. Furthermore, when trading during volatile events or overnight session handovers, a local MQL5 EA continues executing its SL/TP modifications and Trap Door locks even if an external Python process or internet bridge disconnects. We use Python strictly where it excels: vectorized multi-year historical auditing, Monte Carlo simulations, and trade rejection telemetry.

Edge Infrastructure Asked by @CloudArchitect • 1 week ago

Why did you build Alumungandr on Cloudflare Workers and Pages instead of a traditional Ubuntu VPS?

A
David Anthony Jones (Alu) ✓ Founder Answer

Single-point VPS servers are brittle. If you host on a single droplet in New York, a user in Kingston, Jamaica or Tokyo suffers 150–250ms of latency. Cloudflare Pages and Workers execute across 330+ edge data centers with sub-10ms latency globally, zero cold starts, zero Linux OS kernel maintenance, and native enterprise DDoS absorption. With Cloudflare R2 offering $0 egress fees and Workers AI running models at the edge, it is the most resilient, cost-effective infrastructure for independent software founders.
