🛡️ ZERO-KNOWLEDGE ARCHITECTURAL SPECIFICATION

1. Client-Side AES-256-GCM

Files are converted into binary buffers and encrypted with native browser cryptography (Web Crypto API) before transmission. The plaintext data never touches the network wire.

2. Zero-Knowledge Key Isolation

The 256-bit symmetric key is appended strictly to the URL fragment (#key=...). According to HTTP standards (RFC 3986), fragment identifiers are never transmitted to web servers, reverse proxies, or DNS logs.

3. Automated TTL & Self-Destruct

Payloads are cached directly across Cloudflare's edge network and automatically purged when the TTL expires. When "Burn after reading" is enabled, the edge worker deletes the ciphertext the exact instant it is claimed.
