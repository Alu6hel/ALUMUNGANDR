Edge Worker Endpoint Directory

All endpoints run natively on Cloudflare Pages Functions. You can invoke them headlessly from packaging ERPs, CI/CD pipelines, or DualMark CLI instances.

GET /01/{gtin}[/10/{lot}[/21/{serial}]]
Direct RFC 9264 GS1 Digital Link entrypoint. Performs automatic content negotiation based on Accept header and query parameters (?linkType=pip|epcis|sds|all).
GET /api/dualmark/resolve?gtin={gtin}&linkType={type}
Headless resolver endpoint returning Linkset JSON-LD or EPCIS 2.0 records with RFC 8288 Link headers.
POST /api/dualmark/fsma
Ingests and notarizes FDA FSMA 204 CTE events, verifies WebCrypto ECDSA P-256 signatures, and issues SHA-256 Merkle audit receipts.
GET / POST /api/dualmark/recall
Queries or arms the emergency safety recall kill-switch for immediate barcode redirection across global retail POS.
POST /api/dualmark/verify-license
Stateless verification of offline HMAC-SHA256 DualMark Studio commercial tokens.
GET /api/dualmark/status
Health telemetry, active route counters, edge colocation identifier, and free-tier quota status.
